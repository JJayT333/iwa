# Handoffs

Keep immutable, redacted workstream handoffs here. Name each file
`YYYY-MM-DD-<workstream>.md`, record UTC creation time, project and repository
identity, branch and HEAD, dirty counts, objective, remaining work, approval
needed, resume instructions, stop conditions, and sensitivity class. Do not
include machine paths, private filenames, credentials, or transcript excerpts.
The repository-root `CONTINUATION-PROMPT.md` is an index only.
