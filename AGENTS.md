# Agent Guidance

Work only inside this repository. Inspect before changing, never expose secrets,
never overwrite existing paths, and do not commit, publish, install, or change
authentication without explicit approval.

This repository must remain under the machine's configured project root. Do not
create replacement source trees in task workspaces, Documents, Downloads,
cloud-sync folders, a home-directory root, or temporary directories.

Replace the verification placeholders in `README.md`, then run every applicable
build, lint, format-check, typecheck, test, and security command before claiming
completion. Report evidence and changed files.

Use one active agent per checkout. Approved concurrent work requires separate
branches or worktrees.
